# EduPulse Connector Catalog

## User-provided reference

Keep the [Glama App Automation catalog](https://glama.ai/mcp/servers?attributes=category%3Aapp-automation) as a discovery reference for future EduPulse integrations.

The catalog is not an approval list. Before adding any service, verify its official endpoint, whether “free” means genuinely keyless or only free software around a paid API, data handling, authentication scope, maintenance activity, rate limits, licensing, deployment compatibility, and whether it directly benefits school administration, educator CRM, approved knowledge ingestion, visitor support, email delivery, or the Windows desktop workflow.

Each proposed connector must be isolated from private student data by default. Public-web search or scraping may discover candidate sources, but the content must be normalized, cited, and approved before it becomes institution knowledge. Connector credentials must stay server-side and must never be placed in browser code or public repository files.
