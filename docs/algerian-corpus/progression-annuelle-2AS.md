# Progression Annuelle — Anglais 2AS (2020, SE2)
Source: Studocu Plan Annuel 2020-english 2as (Leila zaiter) + Ministry GIP notes

## Context
- Ministry via General Inspectorate of Pedagogy issued **learning progressions** as complementary tool to reference docs (curriculum + supporting docs). Replaces time-bound linear annual distributions which imposed date/time/sessions rigidly. Progressions allow coherence with pedagogic assessment plan and focus on pre-requisites regulation.

## Guidelines
- Bold = pre-requisites. At beginning of each unit, teachers check assimilation via diagnostic test and regulate accordingly.

## Level: Secondary Education Year Two (SE2)
- **Streams: Scientific: 3h/week**
  - Themes: 1 Poverty and World Resources - Waste not, want not; 2 Technology and Innovation - Budding scientist; 3 Disasters and Safety - No Man is an Island (details truncated but table includes assessment)
- **Streams: Foreign Languages: 5h/week**
  - Exit Profile: At end SE2, learner will be able to produce oral/written messages/texts of descriptive, narrative, argumentative, expository types.
  - Units include: Safety, Resolution, Technology and Arts - Fiction or Reality, Disasters and Safety - No Man is an Island
  - Assessment: regular intervals during sequence + end sequence + exam periods; after 3/4 weeks mobilize resources in problem-solving via pair/group project.

## Assessment Pattern (both streams)
- Regular formative + end sequence + exams.
- After 3/4 weeks: pair/group problem-solving to reinvest resources.
