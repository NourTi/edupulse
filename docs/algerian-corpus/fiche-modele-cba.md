# Fiche Pédagogique Modèle — APC/CBA (Seed)
Source: apprendre.auf.org (Exemple fiche APC 5e Expression Écrite) + DPF C I Module Allemand 2018 + lecoursgratuit.com

## Fiche APC — Structure Officielle (Lycée)

### En-tête
- Niveau / Filière / Classe / Effectif / Date / Durée / Séquence / Séance / Projet
- Compétence terminale visée (code programme)
- Objectif opérationnel: "À la fin, l'apprenant sera capable de..."
- Ressources: savoirs (lexique, grammaire, phonologie), savoir-faire (écouter/parler/lire/écrire), savoir-être (citoyenneté, valeurs)

### Déroulement CBA (3 phases + évaluation)

**I. Phase de présentation (5 mn)**
- Situation problème de départ (obstacle, complexe, réel, motivant — Chabot/Rogiers "integrative situation")
- Éveil / mise en situation, annonce activité du jour, tâche élève

**II. Phase de développement (45-50 mn)**
- Traitement de la situation:
  - Identification du type d'écrit / tâche
  - Recherche des idées (collectif)
  - Organisation des idées (plan introduction-développement-conclusion)
  - Rédaction collective / individuelle
- Didactique: construit savoir via confrontation sans solution initiale (collectif + individuel)

**III. Phase d'évaluation / Situation d'évaluation (20 mn individuel + 25 mn correction)**
- Situation d'évaluation suivie de 2-4 consignes (individuel)
- Récapitulation: point des habiletés installées (10 mn)
- Traces écrites

### Éléments Fonctionnels (APC)
- **Fonction didactique:** build knowledge via active engagement.
- **Fonction intégrative:** intégration des acquis (savoirs+habileté+attitudes) — compétence = mobilisation dans situation complexe avec plusieurs réponses possibles.

### Supports & Différenciation
- Manuel officiel, tableau, fiches, ardoise, documents authentiques.
- Différenciation: remédiation faibles / enrichissement forts; peer assessment for project.
