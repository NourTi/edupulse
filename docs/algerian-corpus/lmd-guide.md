# LMD Guide — University Algerian System (Seed)
Source: univ-boumerdes Guide pratique LMD 2011 + UMMTO fdsp + Aleph + DSpace El Oued Study Skills

## Structure
- Licence: 6 semestres = 180 crédits (30/semestre) = Bac+3
- Master: 4 semestres = +120 crédits (30/sem) = Bac+5 (Licence +2). Two tracks: Master Professionnel (formation large) vs Master Recherche (prépare doctorat)
- Doctorat: 6 semestres minimum recherche après Master = Bac+8
- Paradigme: semestralisation, not année; progression annuelle via crédits.

## UE Types
- UEF = Unité d'Enseignement Fondamental
- UEM = Méthodologique
- UED = Découverte
- UET = Transversale
- Each UE: cours, TD, TP mix. Equivalence: 1h cours = 1h30 TD = 2h TP. Reference: 32 weeks/year → 192h cours = 288h TD = 384h TP (6h / 9h / 12h per week)

## Evaluation
- Semestrielle, progression annuelle. 2 sessions per semester: normale + rattrapage (session 2).
- CC (Contrôle Continu) + examen final, may combine. CC: questions ponctuelles, 20 min in TD/TP, covers cours/exercices/TP/travail personnel.
- Assiduité TD/TP obligatoire (Art 24 Arrêté 136). PV, feuille collecte notes, relevé notes, attestation, annexe descriptive au diplôme.

## Study Skills Unit Example (LMD First-Year)
- Lessons: How to Succeed at University, LMD System, Learning styles, Study habits, Note Taking, Time Management (SMART: Measurable, Achievable, Realistic, Time-based), Goal Setting, Exam Prep, Effective Reading, Presentation, Learning Strategies.
- Management: Make Lists, Break down tasks, prioritize, Take Responsibility, Align with Values.
